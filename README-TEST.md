# كل صفحة من ملف JSON واحد

الملف الذي ينتهي اسمه بحرف t هو:

```text
data/01j5bs3egwdcmzccgpyxns8y0t7t.json
```

هذا الملف يحتوي على بياناته الأصلية، وداخل `view` كل ما يخص عرض صفحته: العناوين، أسماء الحقول، أعمدة الجداول، بادئة رقم الترخيص، تعريف الحالات وألوانها، بيانات الصور ومساراتها، عنوان التبويب، لغة الصفحة، ملفات التنسيق، ورسائل الخطأ الخاصة به.

تم حذف ملف الإعداد المشترك. كل ملفات السجلات أصبحت مستقلة بالطريقة نفسها، دون تغيير بيانات المنشآت. العارض يجلب ملف JSON المطلوب فقط ويقرأ إعدادات العرض من `view` داخله؛ لا يجلب JSON آخر لتكملة بيانات الصفحة.

## الاختبار في VS Code

1. فك الضغط وافتح المجلد الذي يحتوي على `index.html` عبر File > Open Folder.
2. أوقف Live Server القديم إن كان شغالًا، ثم شغل Live Server من هذه النسخة. الإعدادات اللازمة مرفقة داخل `.vscode/settings.json`.
3. افتح الرابط التالي، مع تغيير المنفذ لو كان مختلفًا:

```text
http://127.0.0.1:5500/license/view/01j5bs3egwdcmzccgpyxns8y0t7t/
```

## إضافة صفحة جديدة بملف واحد

1. انسخ ملف `01j5bs3egwdcmzccgpyxns8y0t7t.json` داخل `data/` باسم جديد مثل `new-record.json`.
2. عدل البيانات داخله. عدل `view` أيضًا لو أردت عناوين أو إعدادات مختلفة لهذه الصفحة وحدها.
3. افتح `/license/view/new-record/`.

اسم الملف بدون `.json` هو معرف المسار. استخدم الحروف الإنجليزية والأرقام والشرطة `-` أو `_`، بحد أقصى 128 حرفًا. لا يوجد routeId مطلوب، ولا قائمة أسماء، ولا تعديل HTML عند الإضافة.

للبدء ببيانات فارغة، انسخ `templates/record.template.json` إلى `data/` باسم جديد. هذا النموذج يحتفظ بإعدادات `view` الكاملة؛ كل بيانات السجل داخله فارغة. الحقول الناقصة تظل فارغة ولا تستعير بيانات من سجل آخر. ملف `{}` وحده ليس نموذجًا مكتملًا لأنه لا يحتوي على `view`.

الرابط البديل `index.html?id=new-record` يعمل أيضًا على خوادم الملفات الثابتة.

## GitHub Pages — إعداد مرة واحدة

استبدل ملفات النسخة السابقة بمحتويات الحزمة، واحذف ملف `data/site-config.json` القديم من المستودع وأي مجلدات سجلات HTML قديمة داخل `license/view/`، مع الاحتفاظ بملف `license/view/index.html` المرفق. تأكد من رفع `.github` و`.vscode` و`.nojekyll` أيضًا؛ GitHub Desktop يرفع المجلدات المخفية.

اختر Settings > Pages > Build and deployment > Source > GitHub Actions مرة واحدة. بعد ذلك ارفع ملف JSON الجديد فقط إلى `data/` على الفرع الافتراضي، وانتظر نجاح Build JSON routes and publish Pages. ملف البناء المرفق ينشئ المسارات وينشرها تلقائيًا؛ لا تحتاج لتشغيله يدويًا لكل إضافة. ملفات HTML الناتجة بلا بيانات، وتوجد داخل `_site` وقت البناء فقط.

المسارات المبنية للسجلات الموجودة ترجع HTTP 200. توجد 404 مخصصة كحل احتياطي، لكنها تظل HTTP 404 إذا لم ينفذ البناء. فتح الدومين وحده أو معرف غير موجود يعرض Error 404؛ عند تعذر قراءة أي سجل يظهر رمز خطأ تقني عام، دون تحميل ملف سجل آخر للحصول على نص رسالة.

الصور والخطوط وملفات CSS وJavaScript تظل أصولًا للموقع، ومسارات صور الصفحة وتنسيقها محددة داخل ملفها. لم يتم نشر هذه الحزمة على مستودعك أو دومينك من هذه المحادثة.
